## 12 类钩子

每类给出：**为什么有效**（机制）、**句式骨架**（〈〉是可替换槽）、**本品实例**、**写坏的样子**。
骨架是脚手架不是模板——同一个钩子每次都要换说法，靠的是机制理解，不是填空。

### 1. 社交证明（第三方追问）

**机制**：自己夸产品，读者自动打折；别人的反应，读者当证据。这类钩子的点击率长期最稳，因为它同时给了社交想象——"我也想被人这么问"。

**骨架**：〈他人〉+〈追问/反应〉+〈次数或程度〉+〈留白〉
- 同桌问了我三次这个挂件哪买的
- 我妈第一次主动问我追星的东西
- 一整排都回头看我书包上那个

**写坏的样子**：「大家都说我这个挂件好看」——"大家"不是具体的人，"好看"是评价词，两层都虚。改法：把"大家"换成一个具体的人（同桌/室友/同事/我妈/邻座），把"好看"换成一个动作（转过来问、掏出手机搜、回头看）。

### 2. 数字锚（价格 / 次数 / 数量）

**机制**：数字是滑动惯性的断路器，眼睛会先落在数字上。而且数字自带可信度——具体到某个数的人像是真的干过这件事。

**骨架**：〈数字〉+〈动作〉+〈结果〉
- 39块把本命歌单挂在了书包上
- 这个月我换了8次歌单，一次没麻烦
- 一碰进超话，每天打卡少点8下

**写坏的样子**：「花了一点钱买了个很值的挂件」——"一点钱""很值"都是模糊量。改法：给出确切数，哪怕是"不到一杯奶茶"这种换算式锚点也远好于"便宜"。

### 3. 身份认领（人群前置）

**机制**：把人群词放在前面，等于在人群里喊名字，被喊到的人会停下。代价是放弃了泛人群，但小红书的推荐逻辑吃的就是精准。

**骨架**：〈人群〉+ 的 +〈刚需/发现/自救方案〉
- 高中生的追星刚需，我们宿舍传疯了
- 打工人的工牌可以这么玩
- i人靠这个和同事破了冰

**写坏的样子**：「追星女孩必备好物」——"追星女孩"太宽，等于没标签，"必备好物"是货架话术。改法：把人群下切一层（高中生/大学生党/上班第一年/异地党/毕业生），把"必备"换成一个具体处境。

### 4. 否定式反常识

**机制**：否定句制造认知冲突，读者要么反驳要么求证，两种都得点进来。"原来…"是它的温和变体，卖的是信息差。

**骨架**：别再〈常见做法〉了 ／ 原来〈事物〉还能〈意外用法〉 ／ 不是〈以为的〉，是〈实际的〉
- 别再买大街上人手一个的挂件了
- 原来NFC还能这么玩？我玩疯了
- 挂件不是买来看的，是买来用的

**写坏的样子**：「千万不要错过这个挂件」——伪否定，句子本质还是推销。改法：否定必须指向读者**正在做的某件具体事**（买同款挂件、把钥匙和卡分开带、手动翻APP找歌），这样冲突才成立。

### 5. 场景切片

**机制**：给出时间＋地点＋动作，读者的画面自动开机，代入速度比任何形容词都快。场景越窄越有效。

**骨架**：〈时间/地点〉+〈动作〉+〈结果或反差〉
- 上班摸鱼一碰就追剧，同事没发现
- 晚自习下课那段路，我一次没掏过手机
- 演唱会散场那天，我靠它撑住了

**写坏的样子**：「日常生活中很好用」——"日常生活"是没有场景的场景。改法：切到一个具体的十分钟（早高峰地铁、午休40分钟、进校门刷卡那下、散场走去地铁站那段路）。

### 6. 悬念留白

**机制**：句子不说完，认知上就留了一个开口。人对未完成的东西有强迫性的收尾欲，这是最省字的钩子。

**骨架**：〈事件〉+ …（〈半句感慨〉  ／ 〈结果〉，但没人猜到〈原因〉
- 送闺蜜这个她当场哭了…（早买啊
- 我的工牌卡套会自己放歌（离谱
- 挂了一个月，同事以为我换了新手机

**写坏的样子**：「你绝对想不到这是什么」——空悬念，什么信息都没给，读者只感到被耍。改法：**留白必须建立在已经给出的具体事实之上**——先给"闺蜜当场哭了"，再留"为什么"；不能只留一个"你猜"。

### 7. 矛盾反差

**机制**：把两个不该同时出现的东西放进一句话，大脑会卡一下，那一下就是点击。反差自带幽默，转发率高。

**骨架**：〈A行为〉，〈得到了相反的评价/结果〉
- 网课一碰就开，我妈以为我自律了
- 上课偷偷追星，班主任还夸我东西整齐
- 明明在摸鱼，看起来像在看工作消息

**写坏的样子**：「又好看又实用」——这不是反差，是两个优点并列。改法：反差要落在**评价的错位**上（做了A，被当成B），不是功能的叠加。

### 8. 拟人 / 魔法化

**机制**：把功能写成物体自己有生命，读者会想知道"这怎么可能"。它是把技术卖点变成好奇心的最短路径——比解释 NFC 强十倍。

**骨架**：〈物件〉会自己〈动作〉 ／ 〈物件〉突然〈拟人行为〉
- 书包上多了个会唱歌的小东西
- 我的工牌卡套会自己放歌（离谱
- 挂件比我先知道我今天想听什么

**写坏的样子**：「智能NFC黑科技挂件」——"智能""黑科技"是标签不是画面。改法：把技术词整个删掉，只留下"它自己做了一件事"这个观察。

### 9. 圈层黑话（暗号筛选）

**机制**：黑话是精准筛子。看不懂的人划走无所谓，看懂的人会觉得"这是我们自己人写的"，信任成本直接归零。追星品类里这类钩子的收藏率最高。

**常用词**：蹲、蹲到了、还愿、本命、墙头、我家哥哥/我姐、超话、打卡、空降、返场、入坑、同担、代拍、谷子、应援色

**骨架**：〈黑话动作〉+〈时长/难度〉+〈结果〉
- 蹲了三周终于蹲到本命色卡套
- 冷门家的姐妹，我们也有周边了
- 同担来认领一下这个颜色

**写坏的样子**：一句里塞四个黑话（"蹲到本命同担墙头应援色"）——过载，圈内人也读不顺。改法：**一条标题最多两个黑话**，其余用普通话把事说清。

### 10. 对比测评（我买过 N 个）

**机制**：带上失败史的推荐才可信。"买过5个只留下这个"隐含了四次踩坑，读者认为你替他试过了，点进去是为了抄结论。

**骨架**：买过/试过〈数量〉个〈品类〉，只〈留下/回购〉了这个 ／ 〈A〉和〈B〉我都用过，差别在〈点〉
- 买过5个追星挂件，只留下了这个
- 亚克力的裂了，毛绒的脏了，最后换了这个
- 挂件和卡套我都买过，合成一个才对

**写坏的样子**：「这个挂件比其他的都好」——没有失败史，也没有具体对比对象，等于自夸。改法：把对比物写具体（亚克力立牌、毛绒挂件、金属牌、徽章），最好带上各自的死法。

### 11. 收益量化（省了多少步）

**机制**：把"方便"翻译成可数的东西。"少点8下"这种句子读者会在心里默算一遍自己的情况，算的过程就是停留。

**骨架**：〈动作〉从〈原来的量〉变成〈现在的量〉 ／ 〈场景〉少了〈可数损耗〉
- 一碰进超话，每天打卡少点8下
- 从解锁到出歌，只剩一个动作
- 出门少带两样东西，包里终于清了

**写坏的样子**：「非常方便省时间」——"方便""省时间"是形容词流水线的重灾区。改法：**任何时候想写"方便"，先问省了几步、几秒、几样东西**，把答案写出来，形容词删掉。

### 12. 稀缺宣示

**机制**：本品最强的结构性优势就是一人一款不撞款。稀缺同时满足身份宣示欲——买它是为了被认出来，不是为了不被认出来。

**骨架**：全世界/全校只有我这一个〈物〉 ／ 〈数量〉个人〈数量〉个颜色，一个都不撞
- 全世界只有我这一个应援色挂件
- 我们宿舍六个人六个色，一个没撞
- 撞款是社死，所以我买了这个

**写坏的样子**：「独一无二限量款」——"独一无二"是评价词，"限量"还可能踩夸大宣传。改法：用可验证的具体范围（我们班、我们宿舍、我们学校、整趟地铁）代替"全世界"式空话，或用数字表达（六个人六个色）。

## 搜索型标题的写法

搜索型不是把钩子拿掉，是**把关键词提到最前面，再挂一个小钩子**。判断标准：这条标题里有没有一个用户真的会去搜索框里打的词。

**结构**：〈搜索关键词〉+〈钩子或利益点〉

本品高价值关键词（按搜索意图分组，一条标题只用一个主关键词）：

| 意图 | 关键词 |
|---|---|
| 品类找货 | NFC挂件、书包挂件、证件卡套、钥匙扣、卡包挂件 |
| 场景找货 | 学生党好物、开学必备、通勤好物、宿舍好物 |
| 送礼 | 生日礼物、毕业礼物、闺蜜礼物、送女生礼物 |
| 圈层 | 追星好物、应援周边、应援色、明星周边 |
| 功能疑问 | NFC怎么用、NFC能干什么 |

**示例**：
- 毕业礼物就买这个，我们班人手一个不同色
- 书包挂件推荐：会放歌的那种，同学全在问
- 学生党好物｜校园卡钥匙追星合成一个
- NFC除了刷公交，还能这么用

**注意**：竖线「｜」分段在搜索型标题里很好用（前段吃关键词，后段放钩子），但一条里最多一个。不要为了塞词把句子写成词组罗列——平台对关键词堆砌有识别，读者也不点。

## 具体锚点素材库

出稿时缺具体细节就从这里取，取完记得换成本批没用过的。

**数字类**：39块 / 不到一杯奶茶 / 问了三次 / 蹲了三周 / 换了8次 / 少点8下 / 买过5个 / 一次买了7个 / 六个人六个色 / 挂了一个月 / 看了十分钟 / 只剩一个动作

⚠️ **数字必须停在日常尺度**。人在生活里会说"三次""五个""一个月"，不会说"87天""11次""23个"——精确到刺眼的数字读起来不像真实经历，像编的，效果和形容词流水线一样糟。宁可写"挂了一个月"也不要写"挂了87天"。

**人物类（可用——圈层能联想到的角色）**：同桌 / 室友 / 前后桌 / 邻座 / 我妈 / 班主任 / 同事 / 组长 / 闺蜜 / 学妹 / 同担 / 一整排人

⚠️ **人物锚点不能取圈外角色**：食堂阿姨、保安、快递员、公交司机、路人——这类人物和追星人群的跨度太大，读者看到就联想不到明星周边，关联性直接断掉。挑人物的标准很简单：**这个人会出现在目标读者每天的生活半径里，并且能让读者想到校园/职场/追星哪一个场景**。班主任、组长这类"权威角色"可以用，但要配上实物词（工牌、追星的东西）才立得住，因为它们靠的是反差。

**地点场景类**：进校门刷卡那下 / 晚自习下课 / 宿舍熄灯前 / 早高峰地铁 / 电梯里 / 工位上 / 午休那40分钟 / 演唱会散场 / 图书馆 / 走去食堂那段路 / 毕业那天的教室

**物件类**：书包拉链 / 校园卡 / 饭卡 / 门禁卡 / 工牌 / 宿舍钥匙 / 耳机 / 亚克力立牌 / 毛绒挂件 / 徽章（扎破书包的那个）

**旁人反应类**：转过来问 / 掏出手机搜 / 回头看 / 愣了两秒 / 当场哭了 / 喊了一声 / 追问了三天 / 以为我换了新手机 / 全班回头

**产品动作类**：手机一贴 / 碰一下 / 歌直接响 / 从上次进度继续 / 重录成别的 / 一串带走 / 塞进卡位

## 人群标签表

用具体的，不用宽泛的。宽泛标签（追星女孩、年轻人、女生）等于没标签。

- **学生线**：高中生 / 大学生党 / 住宿党 / 毕业生 / 考试周的人 / 上网课的
- **职场线**：打工人 / 上班第一年 / 通勤党 / 工牌党 / 摸鱼选手
- **性格线**：i人 / 社恐 / 整理控 / 收纳控 / 手残党 / 细节控
- **关系线**：送闺蜜的 / 给妹妹买的 / 家长视角 / 班级团购 / 同担
- **圈层线**：冷门家的 / 老粉 / 新入坑的 / 蹲周边的 / 打榜期的

## 情绪词表

按强度分档。**一条标题最多一个情绪词**，两个以上就变成情绪表演，反而假。

- **轻**：有点上头 / 挺离谱 / 有点想哭 / 愣了两秒 / 上头了
- **中**：破防 / 心动了 / 真的会谢 / 我玩疯了 / 撑不住了
- **强**：当场哭了 / 我愣在原地 / 眼睛红了 / 传疯了

**避免**：救命、啊啊啊、爆哭、疯了吧（连用叹号和感叹词的那类）——它们已经通货膨胀，读者对纯情绪叫喊免疫，而且容易和情绪词表演绑在一起丢掉具体信息。

## 追星圈层黑话表

| 词 | 意思 | 用在标题里的作用 |
|---|---|---|
| 本命 / 我家哥哥 / 我姐 / 我墙头 | 最喜欢的那位 | 代替真名，规避风险又更亲近 |
| 蹲 / 蹲到了 / 还愿 | 长期等某个东西终于等到 | 自带"来之不易"的情绪 |
| 同担 | 喜欢同一位的人 | 呼唤同类，拉评论 |
| 超话 / 打卡 / 打榜 | 微博社区日常 | 直接对应产品的社交跳转功能 |
| 空降 / 返场 | 明星突然出现／演唱会加唱 | 高情绪场景锚点 |
| 入坑 / 老粉 | 粉龄自述 | 建立身份和资历 |
| 谷子 / 周边 / 代拍 | 圈内消费品类 | 用于对比测评类钩子 |
| 应援色 | 明星专属色 | 本品的核心差异点，可反复用 |

**规则**：一条标题最多两个黑话；黑话不能承担全部信息量，剩下的部分必须让圈外人也读得懂句子结构。

## 形容词流水线黑名单

出稿后逐条扫一遍，命中就改。这些词的问题不是"不好"，是**信息量为零且已被用烂**，读者的眼睛会自动跳过。

**评价词**：宝藏 / 绝绝子 / yyds / 神仙 / 超好用 / 太爱了 / 爱惨了 / 巨好看 / 无脑冲 / 闭眼入 / 必买 / 必入 / 强推 / 狠狠心动 / 谁懂啊（滥用版）/ 谁懂我 / 真香

**空洞修饰**：超级 / 非常 / 特别 / 很值 / 性价比高 / 高级感 / 氛围感（当形容词用时）/ 精致 / 用心 / 良心

**货架话术**：必备好物 / 好物分享（当标题主体时）/ 值得拥有 / 不容错过 / 千万别错过 / 手慢无 / 速冲

**改法三条**：
1. 想写"好用"→ 写出省了几步几秒几样东西。
2. 想写"好看"→ 写出别人的反应，或写出颜色的具体来源（应援色、只有我这一个）。
3. 想写"值"→ 写出价格数字或换算（不到一杯奶茶），或写出用了多久没坏。

**两条例外**：
- 这些词写进**正文**里当口语是可以的，本黑名单只约束标题——标题字数太少，浪费不起。
- 在**搜索型标题**里，"学生党好物""开学必备清单"这类词组是真实存在的高频搜索词，此时它们的身份是关键词而不是评价词，可以用。判断标准很简单：它在句首承担搜索功能（「开学必备清单里，我加了这一个」）就留，它在句中当形容词夸产品（「开学必备的宝藏挂件」）就删。

## 违禁词与合规表

### 绝对化用语（不能用）

最 / 最佳 / 最好 / 最便宜 / 第一 / 唯一（宣称唯一销售/唯一品牌时）/ 绝对 / 100% / 顶级 / 顶尖 / 国家级 / 世界级 / 独家 / 首创 / 永久 / 无敌 / 完美 / 史无前例 / 全网最低 / 销量冠军 / 断货王

注意：「全世界只有我这一个应援色挂件」描述的是**用户个人拥有情况**，不是对商品做绝对化宣传，可以用；「全网唯一的NFC挂件」是对商品的绝对化宣称，不能用。区别在于主语是我还是商品。

### 功能表述红线

| 不能写 | 要写成 |
|---|---|
| 四合一同时使用 / 一碰全都能 | 单次录一个跳转，可以随时重录换成别的 |
| 无需设置自动播放 | 提前把歌单写进去，手机碰一下跳转播放 |
| 所有手机都支持 | 需要手机开启 NFC 功能 |
| 永久使用 / 芯片无限次 | 可以反复重录 |

### 其他

- 不编造销量、榜单、排名、明星本人使用/授权。
- 不用医疗功效、心理疗效类表述。
- 不在标题里放引流信息（加V、私信、微信、链接在评论区）。
- 明星真名：默认用代称，用户明确要求才写进标题，并提示肖像权与平台监管风险。
- 应援色/专属元素/超话名以用户提供的资料为准，资料缺失时用不点色号的通用写法（"你本命的应援色"），并在汇报里标注需要补充。

## 句式骨架的抽象方法

检查一批标题有没有自我复制时，靠的是比骨架而不是比字面。做法：**把可替换的具体词换成〈槽位〉，保留句子的结构和语气词**，剩下的就是骨架。

| 标题原文 | 抽象出的骨架 |
|---|---|
| 同桌问了我三次这个挂件哪买的 | 〈他人〉问了我〈次数〉这个〈物〉哪买的 |
| 39块把本命歌单挂在了书包上 | 〈价格〉把〈内容〉挂在了〈物件〉上 |
| 蹲了三周终于蹲到本命色卡套 | 蹲了〈时长〉终于蹲到〈物〉 |
| 网课一碰就开，我妈以为我自律了 | 〈功能场景〉，〈他人〉以为我〈正面评价〉 |
| 买过5个追星挂件，只留下了这个 | 买过〈数量〉个〈品类〉，只留下了这个 |

**判定同骨架**：结构相同、只换了槽内容的，算同一个骨架，即使字面不同。
- "同桌问了我三次这个挂件哪买的" 和 "室友追问了我两天这个是哪买的" —— **同骨架**，同一批里只能留一条。
- "同桌问了我三次这个挂件哪买的" 和 "我妈第一次主动问我追星的东西" —— **不同骨架**（都是社交证明大类，但后者的钩子落在"第一次主动"这个反差上，句子结构也不同）。

所以同一个钩子类型要出多条时，正确做法是**在这个类型里换钩子落点和句子结构**，而不是在同一骨架上换词。换词只是把同一条标题说了两遍，用户挑的时候会当成一条。

跨批次不受这条约束——数据好的标题反复发是对的，本节只用于自查同一批内部。
